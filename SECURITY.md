# Security Policy

## Supported Versions

The following versions of **NeuroPulse** currently receive security updates:

| Version | Supported          |
| :---    | :---               |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security and integrity of physiological telemetry and patient data seriously.

If you discover a security vulnerability or sensitive information exposure:

1. **Do not create a public issue** on GitHub.
2. Please report the vulnerability privately by opening a [GitHub Security Advisory](https://github.com/AASHER0777/stress-detection/security/advisories/new) or contacting the maintainers directly via email at `subhapattnaik1@gmail.com`.
3. Please include:
   - Description of the issue and potential impact
   - Step-by-step reproduction steps or proof-of-concept
   - Suggested mitigations (if known)

We will review your submission promptly, validate the findings, and coordinate a patch release.
